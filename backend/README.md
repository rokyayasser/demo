# Medical Appointment System - Backend

A comprehensive medical appointment booking system built with Node.js, Express, and MongoDB.

## Features

- 👥 **Multi-role system** (User, Doctor, Admin)
- 📅 **Appointment scheduling** with time slots
- 💳 **Payment integration** via Paymob
- 📧 **Email notifications** for appointments
- 📁 **File uploads** for medical records
- 🔒 **JWT-based authentication**
- 📊 **Admin dashboard** with analytics
- 🏥 **Doctor portal** for patient management
- 🌍 **Arabic language support**

## Technology Stack

- **Runtime**: Node.js (>=18.0.0)
- **Framework**: Express.js
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT (JSON Web Tokens)
- **File Storage**: Cloudinary
- **Payment**: Paymob
- **Email**: Nodemailer with Gmail
- **Validation**: Joi
- **Security**: Helmet, CORS, Rate limiting
